☀️ El Sol que Explota

Un pequeño sol aparece en el horizonte y, cuadro a cuadro, crece sin control hasta llenar todo el cielo. La clave está en una variable que aumenta en cada ejecución de draw().

Variable de estado

sunSize guarda el diámetro del sol y se incrementa en 1 por cada frame.

Orden de dibujo

Primero el cielo y el sol, después el pasto: el pasto tapa la mitad del sol, como un horizonte.

Animación

draw() se repite ~60 veces por segundo y redibuja todo el lienzo.

Ver código p5.js 
var sunSize = 30;

function setup() {
    var c = createCanvas(400, 400);
    c.parent('canvas-holder');
    noStroke();
}

function draw() {
    background(82, 222, 240);          // cielo azul

    fill(255, 204, 0);                 // sol
    ellipse(200, 298, sunSize, sunSize);

    fill(76, 168, 67);                 // pasto
    rect(0, 300, 400, 100);

    sunSize = sunSize + 1;
}
