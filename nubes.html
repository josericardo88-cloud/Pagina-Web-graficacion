☁️ Nubes que se Separan

Dos nubes, cada una hecha con tres elipses, se alejan en direcciones opuestas y dejan al descubierto un sol que va creciendo detrás de ellas.

Movimiento opuesto

leftX-- mueve la nube izquierda y rightX++ la derecha.

Nubes compuestas

Cada nube es una elipse grande con dos pequeñas a ±62 px; al usar leftX como referencia las tres se mueven juntas.

Sol creciente

sunRadius += 2 agranda el sol en cada frame.

Ver código p5.js 
var leftX = 136;
var rightX = 266;
var sunRadius = 100;

function setup() {
    var c = createCanvas(400, 400);
    c.parent('canvas-holder');
    noStroke();
}

function draw() {
    background(184, 236, 255);

    fill(255, 170, 0);
    ellipse(200, 100, sunRadius, sunRadius);

    fill(255, 255, 255);
    // nube izquierda
    ellipse(leftX, 150, 126, 97);
    ellipse(leftX + 62, 150, 70, 60);
    ellipse(leftX - 62, 150, 70, 60);

    // nube derecha
    ellipse(rightX, 100, 126, 97);
    ellipse(rightX + 62, 100, 70, 60);
    ellipse(rightX - 62, 100, 70, 60);

    leftX--;
    rightX++;
    sunRadius += 2;
}
