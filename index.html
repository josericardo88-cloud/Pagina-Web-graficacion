¡Bienvenido a mi sitio web de gráficos y animaciones!

Este sitio web forma parte de la transición de los retos realizados en el simulador de Khan Academy hacia un entorno de desarrollo web real utilizando HTML5, CSS3 y la librería p5.js.

Utiliza el menú superior para navegar entre los apartados teóricos y cada uno de los proyectos gráficos desarrollados.

Desarrollado para la práctica de ingeniería de software y desarrollo web.
