¡Bienvenido a mi sitio web de gráficos y animaciones!

Este sitio web fue desarrollado por José Ricardo Orozco Sauceda como parte de la transición de los retos realizados en el simulador de Khan Academy hacia un entorno de desarrollo web real utilizando HTML5, CSS3 y la librería p5.js con la etiqueta <canvas>.

Utiliza el menú superior para navegar entre los apartados teóricos, el inspector visual del árbol del DOM y cada uno de los proyectos gráficos desarrollados.

Desarrollado por José Ricardo Orozco Sauceda | Ingeniería de Software y Desarrollo Web.
