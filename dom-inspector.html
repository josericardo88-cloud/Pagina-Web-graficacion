Representación Gráfica y Jerárquica del DOM

A continuación se muestra la representación visual del árbol del DOM para las páginas principales del sitio web, destacando la relación jerárquica desde el nodo raíz hasta sus elementos hijos[cite: 1]:

<html> (Raíz del Documento)
<head>
<meta>
<title>
<link rel="stylesheet">
<body>
<header>
<nav> (Enlaces)
<main id="...">
<canvas> (p5.js)

Estructura explicada: El Modelo de Objetos del Documento (DOM) interpreta los documentos HTML como una estructura de árbol jerárquica donde cada etiqueta es un nodo interactuable por JavaScript.
