Representación Gráfica y Jerárquica del DOM

El Modelo de Objetos del Documento (DOM) interpreta cada documento HTML como un árbol: la raíz es <html>, de ella cuelgan <head> y <body>, y cada etiqueta es un nodo que JavaScript puede leer y modificar. Selecciona una página para ver su árbol real (haz clic en un nodo para colapsar o expandir su rama).
