1. La etiqueta HTML <canvas> y sus contextos de renderizado 2D

La etiqueta HTML <canvas> es un contenedor gráfico introducido en HTML5 que permite dibujar gráficos en tiempo real mediante secuencias de comandos (usualmente JavaScript). Por sí sola, la etiqueta es solo un rectángulo transparente; se requiere un contexto de renderizado para dibujar en él.

El contexto 2D (canvas.getContext('2d')) proporciona los métodos y propiedades necesarios para renderizar formas geométricas (rectángulos, círculos, trazos), texto, imágenes y manipular pixeles directamente en un plano cartesiano bidimensional.

2. Fundamentos de la librería p5.js

p5.js es una biblioteca de JavaScript que reimagina Processing para la Web, facilitando la creación de arte interactivo, animaciones y gráficos. Sus pilares fundamentales son:

  • Función setup(): Se ejecuta una sola vez cuando el programa inicia. Se utiliza para definir el tamaño del lienzo (createCanvas()) y configuraciones iniciales.
  • Función draw(): Se ejecuta en un bucle continuo (por defecto 60 veces por segundo). Es ideal para animaciones, manejo de eventos del mouse y redibujado de elementos gráficos.
  • Abstracción del DOM y geometría: Simplifica funciones de dibujo como ellipse(), rect(), line() y el control de colores con fill() y stroke(), haciendo el código intuitivo y portable directamente desde plataformas educativas como Khan Academy.
